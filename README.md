# Bookingsystem

Første fungerende prototype av bookingbyråets kontrollrom.

## Test
Åpne `index.html` lokalt, eller importer repoet i Vercel som et statisk prosjekt.

Funksjoner i denne prototypen:
- Globalt søk
- Opprette arrangement
- Åpne arrangement
- Faner for personer, kjøreplan, teknikk og reise
- Invitere person inne på arrangementet
- Lokal lagring av nye arrangement i nettleseren
